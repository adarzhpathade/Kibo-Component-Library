# Glitch Text

High-energy cybernetic RGB chromatic aberration glitch animation with slice displacement and scanline effects.

## Installation

```bash
npx kibo add glitch-text
```


## Usage

```tsx
import { GlitchText } from "@/components/kibo/glitch-text/component";

export default function Example() {
  return (
    <GlitchText />
  );
}
```

## Component Standards

- **TypeScript**: Fully typed props and return types
- **Tailwind CSS v4**: Utility-first styling with dark mode support
- **SSR Compatible**: Safe execution in Next.js App Router
- **Accessibility**: Keyboard & screen reader friendly
- **Reduced Motion**: Respects `prefers-reduced-motion`
